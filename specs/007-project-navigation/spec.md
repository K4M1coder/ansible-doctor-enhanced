# Feature Specification: Project Navigation & Breadcrumbs (Feature 007)

**Objective**: Implement hierarchical navigation and breadcrumb support for role/collection/project documentation, integrate with project-level docs produced by Feature 006, and provide UI-friendly navigation structure for generated site output.

**Acceptance Criteria**:
- Provide breadcrumbs for role -> collection -> project pages
- Provide index pages with parent/child links
- CLI flag `--breadcrumb-style` to allow configuration of breadcrumb format
- Unit & integration tests for expected breadcrumb output

Refer to `specs/007-project-navigation/tasks.md` for task breakdown.
