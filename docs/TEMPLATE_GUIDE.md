## Overview

ansible-doctor-enhanced uses Jinja2 templates to render Ansible role documentation in multiple formats (Markdown, HTML, reStructuredText). Templates receive a `TemplateContext` containing parsed role information and use custom filters for format-specific escaping and code formatting.

**Supported Formats:**
- **Markdown** (`.md`): Default format, GitHub-flavored Markdown
- **HTML** (`.html`): Standalone HTML with embedded or external CSS
- **reStructuredText** (`.rst`): Sphinx-compatible RST with optional directives

## Getting Started

### Viewing Default Templates

```bash
# List available formats
ansible-doctor templates list

# Show default Markdown template
ansible-doctor templates show markdown

# Show HTML template
ansible-doctor templates show html > my-template.html.j2

# Show RST template
ansible-doctor templates show rst
```

### Creating a Custom Template

```bash
# 1. Export default template as starting point
ansible-doctor templates show markdown > custom-template.j2

# 2. Edit custom-template.j2 with your customizations

# 3. Validate syntax
ansible-doctor templates validate custom-template.j2

# 4. Use custom template
ansible-doctor generate /path/to/role --template custom-template.j2 --output README.md
```

## Template Context

All templates receive a `TemplateContext` object with these top-level variables:

### `role` (Role Object)

The primary data source containing all parsed role information:

```python
role.name: str                    # Role name from directory or meta
role.description: str | None      # Role description from meta
role.metadata: Metadata | None    # Role metadata (author, license, platforms, dependencies)
role.variables: List[Variable]    # All variables from defaults/ and vars/
role.tags: List[Tag]              # Task tags extracted from tasks/
role.todos: List[TodoItem]        # TODO annotations from comments
role.examples: List[Example]      # Example code blocks from annotations
```

**Metadata Object** (`role.metadata`):

```python
role.metadata.author: str
role.metadata.description: str | None
role.metadata.company: str | None
role.metadata.license: str
role.metadata.min_ansible_version: str | None
role.metadata.platforms: List[Platform]      # Platform(name, versions)
role.metadata.dependencies: List[Dependency]  # Dependency(name, version, source)
role.metadata.galaxy_tags: List[str]
```

**Variable Object** (`role.variables[i]`):

```python
var.name: str              # Variable name
var.value: Any             # Default value (can be str, int, bool, list, dict, None)
var.type: str | None       # Inferred type (string, integer, boolean, list, dict)
var.description: str | None  # From @var annotation
var.required: bool         # From @var annotation (default: False)
var.file_path: str         # Source file (defaults/main.yml or vars/main.yml)
```

**Tag Object** (`role.tags[i]`):

```python
tag.name: str                     # Tag name
tag.description: str | None       # From @tag annotation
tag.usage_count: int              # Number of tasks using this tag
tag.file_locations: List[str]     # ["tasks/main.yml:5", "tasks/install.yml:2"]
```

**TodoItem Object** (`role.todos[i]`):

```python
todo.description: str       # TODO description text
todo.file_path: str         # Source file path
todo.line_number: int       # Line number in source
todo.priority: str | None   # Priority level (high, medium, low, critical)
```

**Example Object** (`role.examples[i]`):

```python
example.title: str | None        # Example title
example.code: str                # Example code content
example.description: str | None  # Example description
example.language: str            # Code language (yaml, json, shell, etc.)
```

### `generator_version` (str)

ansible-doctor-enhanced version that generated the documentation:

```jinja2
Generated by ansible-doctor-enhanced {{ generator_version }}
```

### `generation_date` (datetime)

Timestamp when documentation was generated:

```jinja2
Generated on {{ generation_date.strftime('%Y-%m-%d %H:%M:%S') }}
```

### `output_format` (OutputFormat)

The output format enum (used for conditional rendering):

```jinja2
{% if output_format == 'MARKDOWN' %}
# Markdown-specific content
{% elif output_format == 'HTML' %}
<h1>HTML-specific content</h1>
{% endif %}
```

## Custom Filters

Templates have access to format-specific Jinja2 filters:

### `markdown_escape(text: str) -> str`

Escapes Markdown special characters: `` \ ` * _ { } [ ] ( ) # + - . ! ``

```jinja2
{{ role.description | markdown_escape }}
{{ var.value | markdown_escape }}
```

### `rst_escape(text: str) -> str`

Escapes reStructuredText special characters: `\ * ` _ |`

```jinja2
{{ role.description | rst_escape }}
{{ var.name | rst_escape }}
```

### `code_block(code: str, language: str = 'yaml', format: str = 'markdown') -> str`

Formats code blocks with syntax highlighting:

```jinja2
{# Markdown format (default) #}
{{ example.code | code_block(example.language) }}

{# RST format #}
{{ example.code | code_block(example.language, 'rst') }}
```

**Markdown output:**
````markdown
```yaml
web_port: 8080
```
````

**RST output:**
```rst
.. code-block:: yaml

   web_port: 8080
```

### Built-in Jinja2 Filters

All standard Jinja2 filters are available:

```jinja2
{{ role.name | upper }}               # UPPERCASE
{{ role.name | lower }}               # lowercase
{{ role.name | title }}               # Title Case
{{ role.name | replace('_', '-') }}   # String replacement
{{ var.description | default('No description') }}  # Default value
{{ role.variables | length }}         # List length
{{ var.value | tojson }}              # JSON serialization
```

## Template Structure

### Minimal Template

```jinja2
# {{ role.name }}

{{ role.description | default('No description provided.') }}

## Variables

{% for var in role.variables %}
- **{{ var.name }}**: {{ var.description | default('No description') }}
{% endfor %}
```

### Comprehensive Template

```jinja2
# {{ role.name }}

{% if role.metadata %}
**Author:** {{ role.metadata.author }}
**License:** {{ role.metadata.license }}
{% if role.metadata.min_ansible_version %}
**Min Ansible Version:** {{ role.metadata.min_ansible_version }}
{% endif %}
{% endif %}

{{ role.description | default('No description provided.') }}

{% if role.metadata and role.metadata.platforms %}
## Supported Platforms

{% for platform in role.metadata.platforms %}
- **{{ platform.name }}**: {{ platform.versions | join(', ') if platform.versions else 'all versions' }}
{% endfor %}
{% endif %}

{% if role.metadata and role.metadata.dependencies %}
## Dependencies

{% for dep in role.metadata.dependencies %}
- {{ dep.name }}{% if dep.version %} ({{ dep.version }}){% endif %}
{% endfor %}
{% endif %}

{% if role.variables %}
## Variables

{% for var in role.variables %}
### `{{ var.name }}`

{{ var.description | default('No description provided.') }}

- **Type:** `{{ var.type | default('any') }}`
- **Default:** `{{ var.value }}`
{% if var.required %}
- **Required:** Yes
{% endif %}
- **Source:** `{{ var.file_path }}`
{% endfor %}
{% endif %}

{% if role.tags %}
## Tags

{% for tag in role.tags %}
### `{{ tag.name }}`

{% if tag.description %}
{{ tag.description }}
{% else %}
No description provided.
{% endif %}

- **Usage Count:** {{ tag.usage_count }}
- **Locations:**
{% for location in tag.file_locations %}
  - `{{ location }}`
{% endfor %}
{% endfor %}
{% endif %}

{% if role.todos %}
## TODOs

{% for todo in role.todos %}
- **[{{ todo.priority | upper | default('MEDIUM') }}]** {{ todo.description }} (`{{ todo.file_path }}:{{ todo.line_number }}`)
{% endfor %}
{% endif %}

{% if role.examples %}
## Examples

{% for example in role.examples %}
{% if example.title %}
### {{ example.title }}
{% endif %}

{% if example.description %}
{{ example.description }}
{% endif %}

{{ example.code | code_block(example.language) }}
{% endfor %}
{% endif %}

---

*Generated by ansible-doctor-enhanced {{ generator_version }} on {{ generation_date.strftime('%Y-%m-%d %H:%M:%S') }}*
```

## Format-Specific Guidelines

### Markdown Templates

**File:** `ansibledoctor/generator/templates/markdown/role.j2`

**Characteristics:**
- GitHub-flavored Markdown (GFM)
- Fenced code blocks with language tags: ` ```yaml `
- Inline code with backticks: `` `variable_name` ``
- Use `markdown_escape` filter for user-provided content

**Example:**

```jinja2
# {{ role.name | markdown_escape }}

{{ role.description | markdown_escape }}

## Variables

{% for var in role.variables %}
### `{{ var.name }}`

{{ var.description | default('No description') | markdown_escape }}

```yaml
{{ var.name }}: {{ var.value }}
```
{% endfor %}
```

### HTML Templates

**File:** `ansibledoctor/generator/templates/html/role.j2`

**Characteristics:**
- Standalone HTML5 document
- Embedded CSS (default) or external stylesheet
- Table of contents with anchor links
- Semantic HTML tags (`<article>`, `<section>`, `<code>`)

**Example:**

```jinja2
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{{ role.name }} - Ansible Role Documentation</title>
    {% if embed_css %}
    <style>
        body { font-family: Arial, sans-serif; max-width: 1200px; margin: 0 auto; padding: 20px; }
        code { background-color: #f4f4f4; padding: 2px 4px; border-radius: 3px; }
        pre { background-color: #f4f4f4; padding: 15px; overflow-x: auto; }
    </style>
    {% endif %}
</head>
<body>
    <article>
        <h1>{{ role.name }}</h1>
        
        {% if role.metadata %}
        <section id="metadata">
            <h2>Metadata</h2>
            <dl>
                <dt>Author</dt>
                <dd>{{ role.metadata.author }}</dd>
                <dt>License</dt>
                <dd>{{ role.metadata.license }}</dd>
            </dl>
        </section>
        {% endif %}
        
        {% if role.variables %}
        <section id="variables">
            <h2>Variables</h2>
            {% for var in role.variables %}
            <h3><code>{{ var.name }}</code></h3>
            <p>{{ var.description | default('No description') }}</p>
            <dl>
                <dt>Type</dt>
                <dd><code>{{ var.type | default('any') }}</code></dd>
                <dt>Default</dt>
                <dd><pre>{{ var.value }}</pre></dd>
            </dl>
            {% endfor %}
        </section>
        {% endif %}
    </article>
</body>
</html>
```

### reStructuredText (RST) Templates

**File:** `ansibledoctor/generator/templates/rst/role.j2`

**Characteristics:**
- Sphinx-compatible RST
- Optional Sphinx directives (`.. warning::`, `.. note::`, `.. code-block::`)
- Field lists for metadata
- Proper heading underlines (=, -, ~, ^)

**Example:**

```jinja2
{{ role.name }}
{{ '=' * role.name | length }}

{{ role.description | rst_escape }}

{% if role.metadata %}
Metadata
--------

:Author: {{ role.metadata.author | rst_escape }}
:License: {{ role.metadata.license | rst_escape }}
{% if role.metadata.min_ansible_version %}
:Min Ansible Version: {{ role.metadata.min_ansible_version }}
{% endif %}
{% endif %}

{% if role.variables %}
Variables
---------

{% for var in role.variables %}
``{{ var.name | rst_escape }}``
{{ '~' * (var.name | length + 4) }}

{{ var.description | default('No description') | rst_escape }}

:Type: ``{{ var.type | default('any') }}``
:Default:

{{ var.value | code_block('yaml', 'rst') }}
{% endfor %}
{% endif %}

{% if sphinx_compat and role.todos %}
TODOs
-----

{% for todo in role.todos %}
{% if todo.priority in ['high', 'critical'] %}
.. warning::
   **[{{ todo.priority | upper }}]** {{ todo.description | rst_escape }}
   
   Location: ``{{ todo.file_path }}:{{ todo.line_number }}``
{% else %}
* **[{{ todo.priority | upper | default('MEDIUM') }}]** {{ todo.description | rst_escape }} (``{{ todo.file_path }}:{{ todo.line_number }}``)
{% endif %}
{% endfor %}
{% endif %}
```

**Sphinx Directives:**
- `.. code-block:: yaml` - Syntax-highlighted code blocks
- `.. warning::` - Warning admonitions for high/critical TODOs
- `.. note::` - Informational notes
- `.. toctree::` - Table of contents trees (for documentation sets)

## Validation

### Syntax Validation

```bash
# Validate Jinja2 syntax
ansible-doctor templates validate my-template.j2
```

**Validation checks:**
- Jinja2 syntax errors (unclosed tags, undefined filters)
- Template parses without errors
- Error messages with line numbers

### Programmatic Validation

```python
from ansibledoctor.generator import TemplateValidator, TemplateEngine

engine = TemplateEngine.create()
validator = TemplateValidator(engine.environment)

# Validate syntax
template_source = Path("my-template.j2").read_text()
try:
    validator.validate_syntax(template_source, template_name="my-template.j2")
    print("✓ Syntax valid")
except TemplateValidationError as e:
    print(f"✗ Syntax error: {e}")

# Check undeclared variables
vars_used = validator.get_undeclared_variables(template_source)
print(f"Variables used: {vars_used}")

# Comprehensive validation
result = validator.validate_template(
    template_source,
    template_name="my-template.j2",
    required_vars={"role", "generator_version", "generation_date"}
)

print(f"Valid: {result['valid']}")
print(f"Errors: {result['errors']}")
print(f"Warnings: {result['warnings']}")
print(f"Undeclared variables: {result['undeclared_variables']}")
```

### Testing Templates

Write unit tests for custom templates:

```python
import pytest
from pathlib import Path
from ansibledoctor.generator import TemplateEngine, TemplateContext, OutputFormat
from ansibledoctor.models import Role, Metadata, Variable

@pytest.fixture
def template_engine():
    return TemplateEngine.create(template_dir=Path(__file__).parent / "templates")

@pytest.fixture
def sample_role():
    return Role(
        name="test-role",
        description="Test role description",
        metadata=Metadata(author="Test Author", license="MIT"),
        variables=[
            Variable(name="web_port", value=8080, type="integer", description="Web server port")
        ],
        tags=[],
        todos=[],
        examples=[]
    )

def test_custom_template_renders(template_engine, sample_role):
    """Test custom template renders without errors."""
    template = template_engine.get_template("custom.j2")
    context = TemplateContext(
        role=sample_role,
        generator_version="0.3.0",
        output_format=OutputFormat.MARKDOWN,
    )
    
    result = template.render(**context.to_dict())
    
    assert "test-role" in result
    assert "Test Author" in result
    assert "web_port" in result

def test_custom_template_escapes_special_chars(template_engine, sample_role):
    """Test custom template properly escapes special characters."""
    sample_role.description = "Role with **asterisks** and _underscores_"
    template = template_engine.get_template("custom.j2")
    context = TemplateContext(role=sample_role, generator_version="0.3.0", output_format=OutputFormat.MARKDOWN)
    
    result = template.render(**context.to_dict())
    
    # If using markdown_escape filter
    assert "\\*\\*asterisks\\*\\*" in result
    assert "\\_underscores\\_" in result
```

## Best Practices

### 1. Use Escaping Filters

Always escape user-provided content to prevent rendering issues:

```jinja2
{# Good #}
{{ role.description | markdown_escape }}
{{ var.description | default('No description') | rst_escape }}

{# Bad - can break rendering if description contains special characters #}
{{ role.description }}
```

### 2. Handle Missing Data

Use `default()` filter or conditional blocks:

```jinja2
{# Option 1: default() filter #}
{{ var.description | default('No description provided.') }}

{# Option 2: conditional blocks #}
{% if var.description %}
{{ var.description }}
{% else %}
No description provided.
{% endif %}
```

### 3. Check for Empty Lists

Always check list length before iterating:

```jinja2
{% if role.variables %}
## Variables

{% for var in role.variables %}
...
{% endfor %}
{% else %}
No variables defined.
{% endif %}
```

### 4. Provide Context

Include metadata about the generated documentation:

```jinja2
---

*Generated by ansible-doctor-enhanced {{ generator_version }}*
*{{ generation_date.strftime('%Y-%m-%d %H:%M:%S') }}*
```

### 5. Use Semantic Structure

For HTML templates, use semantic HTML5 tags:

```html
<article>
  <h1>{{ role.name }}</h1>
  
  <section id="overview">
    <h2>Overview</h2>
    <p>{{ role.description }}</p>
  </section>
  
  <section id="variables">
    <h2>Variables</h2>
    ...
  </section>
</article>
```

### 6. Maintain Consistency

Follow naming conventions:
- Heading hierarchy: H1 (role name) → H2 (sections) → H3 (subsections)
- Variable names: backticks or `<code>` tags
- File paths: monospace font
- Priority levels: uppercase (HIGH, MEDIUM, LOW)

### 7. Test Edge Cases

Test templates with:
- Empty roles (no variables, tags, todos, examples)
- Roles with missing metadata
- Variables with complex values (nested dicts, lists)
- Special characters in descriptions
- Very long variable names or values

## Contributing Templates

To contribute a new template format or improve existing templates:

### 1. Create Template File

Place template in `ansibledoctor/generator/templates/<format>/role.j2`:

```
ansibledoctor/generator/templates/
├── markdown/
│   └── role.j2
├── html/
│   └── role.j2
├── rst/
│   └── role.j2
└── <new_format>/
    └── role.j2
```

### 2. Implement Renderer (if new format)

Create renderer class in `ansibledoctor/generator/renderers/<format>.py`:

```python
from ansibledoctor.generator.protocols import DocumentRenderer

class NewFormatRenderer(DocumentRenderer):
    """Renderer for NewFormat documentation."""
    
    def escape(self, text: str) -> str:
        """Escape NewFormat special characters."""
        return text.replace("\\", "\\\\").replace("*", "\\*")
    
    def code_block(self, code: str, language: str = "yaml") -> str:
        """Format code block in NewFormat."""
        return f"[code lang={language}]{code}[/code]"
    
    def render(self, role, **options) -> str:
        """Render role documentation as NewFormat."""
        # Implementation...
```

### 3. Update OutputFormat Enum

Add new format to `ansibledoctor/generator/output_format.py`:

```python
class OutputFormat(str, Enum):
    MARKDOWN = "markdown"
    HTML = "html"
    RST = "rst"
    NEWFORMAT = "newformat"  # Add new format
```

### 4. Write Tests

Create test file `tests/unit/test_<format>_renderer.py`:

```python
import pytest
from ansibledoctor.generator.renderers.newformat import NewFormatRenderer

class TestNewFormatRenderer:
    @pytest.fixture
    def renderer(self):
        return NewFormatRenderer()
    
    def test_escape_special_characters(self, renderer):
        """Test escaping NewFormat special characters."""
        text = "Text with *asterisks* and \\backslashes\\"
        result = renderer.escape(text)
        assert "\\*asterisks\\*" in result
        assert "\\\\" in result
    
    def test_code_block_formatting(self, renderer):
        """Test code block formatting."""
        code = "web_port: 8080"
        result = renderer.code_block(code, "yaml")
        assert "[code lang=yaml]" in result
        assert code in result
        assert "[/code]" in result
    
    def test_render_complete_document(self, renderer, sample_role):
        """Test rendering complete document."""
        result = renderer.render(sample_role)
        assert sample_role.name in result
        assert sample_role.description in result
```

### 5. Update Documentation

- Add format examples to this guide
- Update README.md with new format usage
- Add format-specific guidelines section

### 6. Submit Pull Request

Follow the [Pull Request Process](CONTRIBUTING.md#pull-request-process):

- Include tests (RED → GREEN → REFACTOR)
- Update CHANGELOG.md under `[Unreleased]`
- Maintain 80%+ coverage
- Pass all CI checks
